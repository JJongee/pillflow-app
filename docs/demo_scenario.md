# 필플로우 시연 순서 (10/11)

서버 모드 기준입니다. 서버·DB가 안 될 때는 목업 APK로 같은 순서를 보여 줍니다(아래 "비상용").

## 준비 (시연 30분 전)

1. PostgreSQL 실행 확인 → `backend`에서 서버 켜기 (`python -m uvicorn main:app --reload`)
2. 에뮬레이터 켜기 → `adb devices`에 `emulator-5554 device` 확인
3. `flutter run --dart-define=USE_MOCK=false` (또는 서버용 APK 설치)
4. 시연 계정을 미리 만들지 않고, 시연 중에 회원가입부터 보여 줌

## 질문 대비

- **왜 시간을 나눠 주지 않나요?** 병용금기는 복용 간격으로 해결되는 문제가 아니라서, 앱이 시간을 나누면 오히려 안전하다고 오해할 수 있어요. 상담 안내만 합니다.
- **"금기 기록 없음"이 안전하다는 뜻인가요?** 아니에요. DUR에 기록이 없다는 뜻일 뿐이라 초록 대신 회색으로 표시합니다.
- **임부금기·노인주의는 왜 판정에 안 들어가나요?** 임신 여부·복용량·복용 시작일을 입력받지 않아서, 사용자에게 해당되는지 알 수 없어요. 참고 정보로만 보여 줍니다.
- **자동 시간표는 몇 정 먹을지도 정해 주나요?** 아니요. 용법 문장에서 하루 횟수와 식전/식후만 읽고, 양은 사용자가 입력합니다.

## 비상용 (서버가 안 될 때)

- 목업 APK(`USE_MOCK=true`)는 서버 없이 같은 흐름이 동작합니다. 화면 위에 "목업 데이터로 실행 중"이 보여요.
- 목업에서 병용금기 예시: `멕시롱액` + `코메키나`, 또는 `바이엘아스피린` + `케토신`
