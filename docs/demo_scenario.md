# 필플로우 시연 순서 (11/22, 최종 발표용)

서버 모드 기준입니다. 서버·DB가 안 될 때는 목업 APK로 같은 순서를 보여 줍니다(아래 "비상용").

## 준비 (시연 30분 전)

1. PostgreSQL 실행 확인 → `backend`에서 서버 켜기 (`python -m uvicorn main:app --reload`)
2. 에뮬레이터 켜기 → `adb devices`에 `emulator-5554 device` 확인
3. `flutter run --dart-define=USE_MOCK=false` (또는 서버용 APK 설치)
4. 시연 계정을 미리 만들지 않고, 시연 중에 회원가입부터 보여 줌

## 질문 대비

- **왜 시간을 나눠 주지 않나요?** 병용금기는 복용 간격으로 해결되는 문제가 아니라서, 앱이 시간을 나누면 오히려 안전하다고 오해할 수 있어요. 상담 안내만 합니다.
- **"금기 기록 없음"이 안전하다는 뜻인가요?** 아니에요. DUR에 기록이 없다는 뜻일 뿐이라 초록 대신 회색으로 표시합니다.
- **임부금기·노인주의는 왜 금기 판정(빨간 배너)에 안 들어가나요?** 임신 여부와 생년월일로 **해당되는지는 알려 줍니다**(해당됨·해당 안 됨·확인 필요). 다만 임신 시기나 개인 상태에 따라 달라서 '금기'로 단정하지 않고, 병용금기·연령금기만 금기 판정에 넣기로 팀이 정했어요(10/12).
- **노인주의는 몇 세부터인가요?** 공식 DUR 노인주의 대상인 만 65세 이상이에요. 생년월일이 없고 태어난 해만 있으면 생일에 따라 갈리는 해는 '확인 필요'로 둡니다.
- **용량주의·효능군중복은 왜 해당 여부를 안 알려 주나요?** 용량주의는 최대량이 아직 숫자로 정리되지 않았고(데이터 담당 검증 중), 효능군은 같다고 바로 중복이 아니라 규칙이 더 필요해요. 참고 정보로만 보여 줍니다.
- **증상으로 찾으면 약을 추천해 주는 건가요?** 아니에요. 설명서 효능 문장에 그 말이 있는 약을 이름순으로 보여 줄 뿐이고, 순위를 매기지 않아요. 화면 위에 약사와 상의하라는 안내가 고정돼 있어요.
- **자동 시간표는 몇 정 먹을지도 정해 주나요?** 아니요. 용법 문장에서 하루 횟수와 식전/식후만 읽고, 양은 사용자가 입력합니다.

- **영양제는 왜 함께 먹어도 되는지 확인이 안 되나요?** 공공 DUR 자료는 의약품 기준이라 영양제 상호작용 자료가 없어요. 상호작용 판정은 자료 한계로 제외하고, 복용 관리만 지원합니다.

## 비상용 (서버가 안 될 때)

- 목업 APK(`USE_MOCK=true`)는 서버 없이 같은 흐름이 동작합니다. 화면 위에 "목업 데이터로 실행 중"이 보여요.
- 목업에서 병용금기 예시: `멕시롱액` + `코메키나`, 또는 `바이엘아스피린` + `케토신`
